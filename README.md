# 📊 Executive Sales Analytics Dashboard

An interactive **Business Intelligence dashboard** built with **Power BI** using the **Sample Superstore** dataset. The dashboard provides executive-level insights into sales performance, profitability, regional trends, customer segments, and product performance through interactive visualizations and KPI-driven reporting.

---

## ✨ Overview

This project demonstrates the complete Business Intelligence workflow, from **data preparation** and **data modeling** to **interactive dashboard development**, enabling stakeholders to make informed, data-driven decisions.

---

## 🚀 Key Features

- 📈 Sales Performance Analysis
- 💰 Revenue & Profit KPIs
- 🌍 Regional Sales Insights
- 🛍 Category & Sub-Category Analysis
- 👥 Customer Segment Analysis
- 🏆 Top Performing Products
- 🎛 Interactive Filters & Drill-Down Analysis

---

## 🛠 Tech Stack

- **Power BI Desktop**
- **Power Query**
- **DAX**
- **Data Modeling**

---

## 🧹 Data Preparation

The dataset was transformed using **Power Query** by:

- Standardizing data types
- Converting date columns using **English (United States)** locale
- Removing duplicate records
- Validating missing values
- Cleaning and formatting text fields
- Verifying numeric columns for analysis

---

## 🔗 Data Modeling

The analytical model was designed by:

- Creating a dedicated **Date Table**
- Establishing relationships between tables
- Developing reusable DAX measures, including:
  - Total Sales
  - Total Profit
  - Total Orders
  - Total Quantity
  - Profit Margin
  - Average Order Value
